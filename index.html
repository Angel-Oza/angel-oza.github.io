Things I've built and shipped

01 Embedded + Wireless
SurakshaLink — Offline Emergency Communication System

Built this because I kept thinking about what happens when a disaster hits and mobile networks go down. The whole point is that it works with zero infrastructure — no internet, no SIM card, nothing. Two ESP32 nodes talk to each other over LoRa radio at 433 MHz with a range of several kilometres. I built the firmware in C++ with proper ACK handling so you actually know when a message got through, and paired it with a browser-based dashboard that shows signal strength, a live message log, and SOS/SAFE/REQUEST commands. The hardest part was debugging the ACK timing — the receive loop was blocking and missing replies coming back.

ESP32 LoRa SX1276 433 MHz Embedded C++ Web Serial API Web Bluetooth HTML / CSS / JS
02 Hardware · Assistive Tech
Gesture-Controlled Wheelchair for Paralysis Patients

Designed a mobility device that lets paralysis patients control movement by bending their fingers. Flex sensors on the hand read the gesture, the microcontroller processes the signal in real time, and the output drives the motors. The focus throughout was making it as low-effort as possible to use — the interaction had to be something someone with limited mobility could actually manage without fatigue. I spent a good amount of time on the signal processing side to get the response feeling natural rather than jerky.

Flex Sensors Microcontroller Real-time signal processing Motor control
03 Embedded · IoT
Night Sky Display — Real-Time Constellation Tracker

Built an LED matrix system that displays actual constellation positions based on where you are and which way you're facing. A GPS module provides location, an orientation sensor gives direction, and I wrote the mapping logic that converts star coordinates into LED positions on the matrix. The interesting challenge was the graph-based algorithm — mapping spherical sky coordinates onto a flat grid accurately enough that the constellation patterns are actually recognisable.

Arduino GPS Module Orientation Sensor LED Matrix Graph Algorithms

Research work
Dhirubhai Ambani Institute of Information and Communication Technology

Coal Mine Digital Twin for Autonomous Fleet Coordination. This ongoing research focuses on designing a Digital Twin of a coal mine to study the coordination of autonomous loading and hauling vehicles under realistic operating conditions. The simulation models a dynamic mining environment where loading points gradually deplete and relocate, requiring the hauling fleet to continuously adapt its routing and coordination strategies. It also incorporates IoT-based sensor monitoring and battery-powered mobile Wi-Fi towers to evaluate communication coverage and operational constraints. The project is being implemented in Python, with animated visualizations and performance metrics that support the analysis of fleet behavior, synchronization, and overall system efficiency.
